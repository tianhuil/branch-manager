# Database Branch Manager - Core Package

This is the core package for the Database Branch Manager (`bm`) CLI tool.

## Installation

```bash
bun install @tianhuil/branch-manager
```

## Usage

See the [main README](../README.md) for usage instructions.

## Development

```bash
# Run tests
bun test

# Run e2e tests (requires ROOT_DATABASE_URL)
bun test:e2e

# Type check
bun run typecheck
```
